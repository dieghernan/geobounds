# gbOpen coverage and boundary metadata

## gbOpen coverage

The map shows the highest available ADM level for each country in the
**gbOpen** release type.

The original license varies by boundary and may include ODbL, CC BY, CC
BY-SA or national open-data terms. Check the current metadata before
reuse.
